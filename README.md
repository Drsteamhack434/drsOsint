### 📊 **Análisis de Reputación del Email**
<p align="left">
  <img src="https://img.shields.io/badge/Reputación-Dominio-yellowgreen" alt="Reputación">
  <img src="https://img.shields.io/badge/Patrones-Usuario-blueviolet" alt="Patrones Usuario">
  <img src="https://img.shields.io/badge/Tipos%20de%20Cuenta-4-lightgrey" alt="Tipos de Cuenta">
</p>

- **Evalúa reputación del dominio** con base de datos especializada
- **Identifica patrones en nombres de usuario**:
  - `Nombre.Apellido` (Formato profesional)
  - `Nombre_Apellido` (Formato técnico)
  - `Nombre+Numeros` (Combinaciones comunes)
  - Iniciales o abreviaciones
- **Clasifica tipo de cuenta**:
  - 🏠 **Personal** (Gmail, Outlook, Yahoo)
  - 🏢 **Profesional** (Dominios corporativos)
  - 🔒 **Privada** (ProtonMail, servicios especializados)
  - 📜 **Legacy** (AOL, servicios antiguos)
- **Proporciona calificación de reputación** (Alta/Media/Baja)
